# Message template

The structure of the one message each person got. Everything in `{braces}` is yours to fill.

```
hey {first name}, I turned part of one of your recent {platform} videos into a {length} second short

this one's free
{one link to a private page with the sample}

I'm testing an editing service, $99/month for 30 shorts like this made from your existing videos. would you like to try the first month?
```

## Checks before it goes out

- Use their first name only if they show it publicly; otherwise leave it out.
- Exactly one link (the sample) and exactly one question.
- The price shows up once.
- No hashtags, no other links, no promises about views.
- Keep it short enough to read on a lock screen.
- Use the same lowercase, plain voice you'd use in a real DM.

## If it goes by email

- Subject: lowercase, 3 to 8 words, e.g. `{first name}, a short from your video`.
- Footer: `not interested? just say so and I won't email again`, plus your business postal address (US
  commercial email law, CAN-SPAM, asks for one).
- Send it from your own domain address, and only once per address.

## Private sample page

- One page per person, with a random URL and `noindex`, showing only their sample.
