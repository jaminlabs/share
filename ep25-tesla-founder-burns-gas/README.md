# AI power, without the unit confusion

A one-page note to use when reading a data-center announcement: [AI-POWER-NOTE.md](AI-POWER-NOTE.md).

It separates a power target from delivered capacity, explains how gas turbines enter the supply chain, and gives a worked MW-to-MWh calculation. Sources checked October 26, 2026. No proprietary data, personal details, or access keys.
